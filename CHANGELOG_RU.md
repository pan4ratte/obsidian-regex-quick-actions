# Список изменений

## 2.2.0

### Новые функции

* **Список изменений в плагине.** Теперь его можно открыть прямо в Obsidian командой «Посмотреть список изменений», а после обновления в настройках появляется уведомление о новой версии.


## 2.1.0

### Новые функции

* **Быстрый поиск и замена.** Одноимённая команда открывает окно для разового запуска regex без сохранения: введите выражение, флаги и замену и примените их к текущей заметке. Подсказка под блоком сообщает, затронет ли замена всю заметку или только выделенный текст. Как и после любого другого запуска, результат можно откатить командой «Отменить последнюю быструю команду».


## 2.0.0

### Новые функции

* **Последовательности команд.** Именованные цепочки быстрых команд, которые выполняются одна за другой. Их создают кнопкой «Новая последовательность команд» в настройках, там же меняется порядок шагов. Каждая последовательность становится отдельным пунктом палитры команд и контекстных меню.
* **Быстрые команды для выделенного текста.** Включите новую настройку «Применять быстрые команды к выделенному тексту», и остальная часть заметки останется нетронутой. Изменённый фрагмент остаётся выделенным, так что к нему можно применить несколько команд подряд.
* **Резервное копирование и восстановление.** Быстрые команды и их последовательности теперь можно экспортировать и импортировать. Экспорт доступен только на компьютере: мобильное приложение не умеет сохранять файлы таким способом.
* **Отмена последней быстрой команды.** Команда «Отменить последнюю быструю команду» откатывает предыдущий запуск целиком — даже если он затронул несколько файлов или всю папку.

### Улучшения и исправления багов

* Быстрые команды и последовательности теперь разделены на две вкладки настроек, у каждой — свой счётчик и своя кнопка создания.
* Плагин лучше адаптирован для мобильных устройств.
* Файлы, которые быстрая команда оставила без правок, теперь не перезаписываются, и запуск на папке не трогает дату изменения каждой заметки.
* Исправлен баг, из-за которого уведомление учитывало даже совпадения, текст которых не изменился, и показывало завышенное число замен.

### Прочее

* Декларативные настройки. Плагин переведён на декларативный API Obsidian 1.13.0 — теперь его параметры можно найти через «Поиск настроек».
* Новая минимальная версия Obsidian. Минимальная версия Obsidian повышена до 1.13.0. На более ранних выпусках Obsidian по-прежнему работает плагин 1.4.2.

## 1.4.0

### Новые функции

* **Быстрые команды для нескольких файлов.** Быструю команду теперь можно применить к любому количеству выделенных файлов.
* **Быстрые команды в контекстных меню.** Из контекстных меню теперь можно запустить любую быструю команду, а не только ту, что выбрана по умолчанию.
* **Obsidian Bases.** Добавлена поддержка Bases.

### Улучшения и исправления багов

* Переработана внутренняя структура плагина.


## 1.3.0

### Крупное обновление: хранение пользовательских данных

* **Наборы правил перенесены в `data.json`.** Раньше они лежали в папке `/regex-rulesets` внутри хранилища. Теперь все пользовательские данные находятся в `data.json`, так что плагин меньше вмешивается в хранилище. Миграция при обновлении проходит автоматически: плагин перенесёт данные в `data.json` и удалит папку `/regex-rulesets`. Если папка не удалилась, это можно сделать вручную.
